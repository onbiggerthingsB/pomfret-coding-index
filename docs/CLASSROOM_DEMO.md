# Demonstrating Coding Index

Science / Advanced Coding. Intended setting: independent student exploration, with a short teacher-led demonstration also possible.

The educational purpose is to help students compare coding resources, explain a choice, and give their existing coding agent a clear, source-backed project brief.

## Demonstration

1. Start with a concrete class project, such as a homework dashboard with due dates and a completed filter.
2. Search for `components for a dashboard`. Explain that search ranks catalog words and synonyms; the rank is not a quality score.
3. Open Material UI or another result. Read its use case, framework, setup estimate and caveat. Compare it with another candidate.
4. Drag a useful icon into My project, or use Add to project. Physics drives exploration and collecting resources. The text list and buttons provide an alternative.
5. Enter the project goal and existing setup. Choose only the resources that deserve comparison; the tray holds up to twelve.
6. Copy the project brief into the student's existing agent chat or download its Markdown file. Ask the agent to inspect the project, compare the candidates, explain its choice and implement within the student's approval rules.
7. Have the student explain one tradeoff and show the resulting interaction. Test keyboard use and a narrow screen.

The public agent guide and search API also allow agents to explore the index directly. A locally running preview is only reachable to agents on the same computer.

## Short peer test

Run this with a beginner, an intermediate student and an advanced student. These are suggested tests, not additional organizer requirements. Do not count simulated test data as a real peer test.

- Give the student a real project goal and the public URL, without narrating each click.
- Ask them to find two relevant references and explain which fits their setup.
- Ask them to build a kit and hand the brief to their agent.
- Record where they hesitate, whether the links work, and whether the resulting choice fits the goal.
- Check the public site on a classroom laptop and school Wi-Fi. Record failures before expanding the catalog.

## Honest limits

The index contains 28,358 references and 90 featured resources. Fourteen featured resources currently include checked documentation guidance. The remaining destinations have not all been individually verified. Setup difficulty is an editorial estimate; a documentation check is not a runtime certification. Kits stay in the current browser and are not shared between devices automatically.
